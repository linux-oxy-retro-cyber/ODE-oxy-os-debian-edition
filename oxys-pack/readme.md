=====================================================
Este é um pack de personalização do Oxy OS, baseado em
Debian GNU/Linux. Ele utiliza scripts, listas, imagens, etc.

O projeto em si é distribuído sob a licença GPLv3,
mas os scripts de lista utilizam a licença MIT. 
As configurações do Calamares mantêm as licenças 
originais de seus respectivos projetos.
