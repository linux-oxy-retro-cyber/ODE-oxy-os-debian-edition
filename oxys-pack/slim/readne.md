# Oxy OS - SLiM Display Manager Theme

Este repositório contém o tema de login para o **SLiM (Simple LogIn Manager)** utilizado na distribuição **Oxy OS**.

## 📌 Sobre o Tema
Este tema foi desenvolvido com base no tema padrão (*default*) do SLiM, recebendo customizações visuais e integração do plano de fundo oficial para garantir a identidade estética do Oxy OS.
