# 🛠️ Galeria e Histórico de Erros — Oxy OS

Esta pasta destina-se ao registro e documentação de falhas, *bugs* e comportamentos inesperados ocorridos durante o ciclo de desenvolvimento e compilação do **Oxy OS**.

---

## 📁 Estrutura do Diretório

```text
erros/
├── README.md
└── imagens/
    └── erros e builds ao longo do desenvolvimento do oxys.tar.xz

📸 Pasta imagens/

Dentro do diretório imagens/, você encontrará um arquivo compactado contendo todas as capturas de tela (screenshots) dos erros catalogados desde o início do projeto.
🎯 Para que serve este repositório de imagens?

    Histórico Visual: Permite visualizar exatamente o que aconteceu em tela (falhas de boot, erros do kernel, travamentos no Calamares, problemas de interface no SLiM, etc.).

    Diagnóstico e Comparação: Ajuda desenvolvedores e colaboradores a identificar se um erro atual já aconteceu antes e qual foi o comportamento do sistema na época.

    Ajuda Comunitária: Facilita para quem está testando ou compilando a ISO comparar o problema enfrentado com o histórico documentado do sistema.

🔍 Como Utilizar

    Navegue até a pasta imagens/.

    Extraia o arquivo compactado:
tar -vzxf builds ao longo do desenvolvimento do oxys.tar.xz
